# CTP headers

These CTP SDK headers are required to compile `bomber_ctp_md` and
`bomber_ctp_td`:

- `ThostFtdcMdApi.h`
- `ThostFtdcTraderApi.h`
- `ThostFtdcUserApiStruct.h`
- `ThostFtdcUserApiDataType.h`

They are from the same CTP 6.7.11 SDK bundle. Keep both shared libraries
in the binding directory on this same SDK version when upgrading.
