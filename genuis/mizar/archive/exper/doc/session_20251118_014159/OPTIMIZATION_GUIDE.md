# 模型优化指南 - 提高IC和准确率

## 当前问题分析

根据训练日志分析，当前模型存在以下问题：

### 1. 过拟合严重
- **训练集IC**: 0.4024 (优秀)
- **测试集IC**: 0.0281 (一般)
- **差距**: 14倍，说明模型在训练集上表现很好，但泛化能力差

### 2. 方向准确率低
- **测试集准确率**: 51.86% (接近随机50%)
- **Walk-Forward平均**: 50.09% ± 1.08%
- **问题**: 模型预测方向的能力很弱

### 3. IC不稳定
- **Walk-Forward平均IC**: 0.0089 ± 0.0147
- **IC变异系数**: 1.65 (稳定性较差)
- **问题**: IC波动大，甚至有负值（Fold 2: -0.0070）

### 4. 特征质量
- **平均IC**: 0.0225
- **最大IC**: 0.0462
- **IC>0.03的因子数**: 81个
- **问题**: 特征质量一般，存在大量低IC特征

## 优化策略

### 策略1: 降低模型复杂度（减少过拟合）

**问题**: 当前 `num_leaves=31, max_depth=6` 导致模型过于复杂

**优化**:
```python
'num_leaves': 15,      # 原值: 31 (降低50%)
'max_depth': 4,        # 原值: 6 (降低33%)
```

**原理**: 降低模型复杂度可以提升泛化能力，减少过拟合

### 策略2: 提高特征筛选标准

**问题**: 当前 `IC_THRESHOLD=0.01` 保留了太多低质量特征

**优化**:
```python
IC_THRESHOLD = 0.02    # 原值: 0.01 (提高2倍)
CORR_THRESHOLD = 0.90  # 原值: 0.95 (降低，去除更多冗余)
```

**原理**: 
- 只保留IC>0.02的高质量特征，过滤噪声
- 降低相关性阈值，去除更多冗余特征对

**预期效果**: 
- 特征数量从265个减少到约150-180个
- 保留的特征平均IC更高，模型更稳定

### 策略3: 增强正则化

**问题**: 当前正则化较弱，无法有效防止过拟合

**优化**:
```python
'lambda_l1': 0.5,         # 原值: 0.1 (增加5倍)
'lambda_l2': 0.5,         # 原值: 0.1 (增加5倍)
'min_data_in_leaf': 200,  # 原值: 100 (增加2倍)
```

**原理**: 增强正则化可以防止模型过度拟合训练数据

### 策略4: 降低学习率

**问题**: 当前学习率0.01可能过快，导致模型不稳定

**优化**:
```python
'learning_rate': 0.005,  # 原值: 0.01 (降低50%)
```

**原理**: 
- 降低学习率可以提升模型稳定性
- 虽然需要更多迭代，但模型更稳定

**配合调整**:
```python
'num_boost_round': 2000,        # 原值: 1000 (增加2倍)
'early_stopping_rounds': 100,   # 原值: 50 (增加2倍)
```

### 策略5: 更激进的采样

**问题**: 当前采样比例0.8仍然较高

**优化**:
```python
'feature_fraction': 0.7,  # 原值: 0.8 (降低12.5%)
'bagging_fraction': 0.7,   # 原值: 0.8 (降低12.5%)
```

**原理**: 更激进的采样可以增加模型多样性，提升泛化能力

## 使用方法

### 方法1: 直接使用优化配置（推荐）

1. 备份当前 `config.py`:
```bash
cp config.py config_backup.py
```

2. 将 `config_optimized_v2.py` 的内容复制到 `config.py`

3. 重新运行训练:
```bash
python main.py
```

### 方法2: 逐步优化（推荐用于实验）

1. 先应用特征筛选优化（策略2）:
   - 修改 `IC_THRESHOLD = 0.02`
   - 修改 `CORR_THRESHOLD = 0.90`
   - 运行并观察效果

2. 再应用模型参数优化（策略1, 3, 4, 5）:
   - 修改 `LGB_PARAMS` 和 `TRAIN_PARAMS`
   - 运行并观察效果

3. 对比结果，选择最优配置

### 预期变化

2. **IC提升**: 测试集IC从0.0281提升到0.05+

## 注意事项

1. **训练时间**: 由于增加了迭代次数，训练时间会延长（约2倍）
2. **特征数量**: 提高IC阈值后，特征数量会减少，但质量更高
3. **学习率**: 降低学习率后，需要更多迭代才能收敛
4. **早停**: 增加了早停轮数，给模型更多机会找到最优解

如果上述优化后效果仍不理想，可以考虑：

1. **特征工程**:
   - 尝试特征组合（如特征交叉）

2. **模型集成**:
   - 尝试多个模型的集成（如Stacking）
   - 尝试不同参数的模型投票

4. **超参数调优**:
   - 使用网格搜索或贝叶斯优化
   - 针对IC和准确率进行优化
